# Acessibilidade web

Para aplicações públicas ou usadas por terceiros, WCAG 2.2 AA é requisito transversal.

- HTML semântico, foco visível, teclado e skip link;
- labels, erros associados e anúncios de mudanças dinâmicas;
- contraste, zoom/reflow e alvos adequados;
- alternativa textual para canvas, vídeo, áudio ou visualizações;
- reduced motion e nenhuma informação transmitida só por cor;
- testes automatizados mais revisão manual e amostra com leitor de tela.

A ferramenta automática não autoriza declarar conformidade total.
